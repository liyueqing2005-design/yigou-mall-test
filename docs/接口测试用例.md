# 易购商城接口测试用例

## 说明

- 基础地址：`http://localhost:8080/api`
- 测试工具：Postman / Apifox / curl。
- 通用断言：`code` 为 `200` 表示成功；业务失败 `code` 为 `500` 且 `message` 为对应错误。
- 数据依赖：`sql/init.sql` 初始化后，商品 ID 1~21、用户 1=买家、2=卖家、3=管理员、订单 ID 1/2 已存在。

---

## 1. 认证接口（/auth）

| 编号 | 名称 | 方法 | 路径 | 请求体/参数 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| API-AUTH-01 | 登录成功 | POST | `/auth/login` | `{"username":"buyer","password":"123456"}` | `code=200`，`data.role=BUYER`，`data.token=demo-token-1` |
| API-AUTH-02 | 密码错误 | POST | `/auth/login` | `{"username":"buyer","password":"wrong"}` | `code=500`，`message=账号或密码错误` |
| API-AUTH-03 | 账号不存在 | POST | `/auth/login` | `{"username":"nobody","password":"123456"}` | `code=500`，`message=账号或密码错误` |
| API-AUTH-04 | 获取演示账号 | GET | `/auth/demo-accounts` | 无 | `code=200`，`data` 长度为 3，含买家/卖家/管理员 |
